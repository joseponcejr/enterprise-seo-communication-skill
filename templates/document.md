# Document mode

Preserve the original. Return a new draft, not an overwrite, unless the user explicitly requests editing the source file.

## Scope note

Source identifier, supplied versus original extent, inspected sections/pages, extraction gaps, audience, and disclosure scope. Keep this note outside the clean executive draft. Never imply a complete-document review from a partial excerpt.

## Clean executive draft

Use the document's purpose, not a compulsory heading count. Usually:
- Main conclusion or update.
- Business significance and supporting evidence.
- Completed, underway, proposed next, and blocked work as relevant.
- A real decision or next action if the source/request establishes one.

Preserve material qualifications. If the input contains no requested decision, do not invent a budget approval or commitment. New recommendations belong in a separate labeled section, unless the user explicitly asked for recommendations and their proposed status is clear.

## Change and evidence record

For material claims: ID/location, permitted source claim, evidence/status, output location or replacement, and any intentional qualification. Split a paragraph containing observation, hypothesis, and proposal.

## Section coverage

For every supplied section: retained / rewritten / moved / omitted / unavailable, with a short reason where needed. Use stable headings or IDs; reconcile sections after chunked work. Distinguish coverage of supplied text from coverage of the original source.

## Missing inputs

Only unresolved information that materially changes the business meaning or recommendation. State exactly what is needed. No generic questionnaire.

All sections, including quoted originals and private-looking notes, must comply with the selected disclosure boundary. Never append secrets or unrelated-client content.
